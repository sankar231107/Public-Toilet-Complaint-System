# Public-Toilet-Complaint-System
The Public Toilet Cleaning &amp; Complaint Management System is a web-based application developed using HTML, CSS, and JavaScript. It helps maintain records of public toilet cleaning activities and complaint registration. The system enables supervisors to monitor cleaning schedules, track complaints, and improve sanitation management.
# 🚻 Public Toilet Cleaning & Complaint Management System

A responsive web application developed using **HTML, CSS, and JavaScript** to manage public toilet cleaning records and complaints. The system helps maintain cleaning schedules, track complaints, and improve sanitation management through an easy-to-use dashboard.
